# Local document corpus

Put real `.docx` files here — ones saved by Microsoft Word — to check the
editor's output against. Documents with tables, images, styles, headers and
footers, footnotes and multilingual text are the most useful.

**This directory is ignored by git.** Office documents carry personal data
inside the file itself: author names, editing history, comments and tracked
changes. Nothing here is committed or leaves this machine.

Test documents used by the automated suite are generated by code instead, so
they can live in the repository safely.

## Running it

```powershell
.\x.ps1 corpus      # or ./x.sh corpus on Linux and macOS
```

Every document here is opened, saved again and compared with what went in.
Each one comes back as **identical** (every byte), **repackaged** (every part,
but the zip around them is written differently), **differs** (and which parts
did), or **converted** — a format like `.doc` or `.rtf` saves as a package, so
there are no bytes to compare and only that it opened is reported.

A document that will not open or will not save is a bug and the command ends
unhappily. A difference is a measurement, not a failure: the list at the end
says which parts differ across how many documents, which is where the next
piece of work is.
